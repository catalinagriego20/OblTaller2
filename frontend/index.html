ℹ️ ¿Cómo funciona la delegación?
  1. Delegar: Le das tu poder de voto a otra persona para una propuesta específica.
  2. El delegado vota: La persona a quien delegaste usa tus tokens para votar.
  3. Restricciones:
    • No puedes votar directamente si ya delegaste
    • Solo puedes revocar si el delegado aún no votó
    • Una vez que el delegado vota, la delegación se consume
